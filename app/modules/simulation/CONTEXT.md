# Simulation

Generates reproducible synthetic factory activity.

## Language

**Scenario Definition**:
A versioned description of an initial state, scheduled events, injected anomalies, and ground truth.

**Scenario Run**:
One execution of a scenario definition with a seed and a virtual clock. The same version and seed reproduce the same state.

**Ground Truth**:
The expected answers a scenario run makes known in advance, against which experiments are evaluated.
